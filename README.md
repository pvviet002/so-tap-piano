# Sổ tập Piano

Trang luyện piano từ con số 0 cho trẻ 6–8 tuổi: lộ trình 20 bài, 13 chương nhạc lý, nốt rơi xuống phím,
đọc nốt, hợp âm, máy đếm nhịp, và chế độ **nghe đàn thật qua micro** (cần mở qua https, vì vậy trang được đăng ở đây).

Mở trang: https://pvviet002.github.io/so-tap-piano/

Nhật ký tập ở bản này lưu trong trình duyệt của từng máy.
